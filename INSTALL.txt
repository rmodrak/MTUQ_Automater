
To install MTUQ_Automater, first download the source code

  >> git clone https://github.com/rmodrak/MTUQ_Automater
  >> cd MTUQ_Automater


Then create a conda environment:

  >> conda env create --name mta --file env.yaml


Finally, add bin/ to PATH

  >> export PATH=$PATH:$PWD/bin 

and add src/ to PYTHONPATH

  >> export PYTHONPATH=$PYTHONPATH:$PWD/src
